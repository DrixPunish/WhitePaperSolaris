# 5.4 Arbre de Recherche Technologique

Le **Labo technologique** est le moteur de progression long-terme. Chaque technologie débloque ou améliore des capacités clés. La recherche est planétaire mais son bénéfice est global (empire entier). _(Sélection des technologies clés ci-dessous — l'arbre complet compte 16 technologies.)_

### 🔩 Technologies de Base

| Technologie               | Effet                                            |
| ------------------------- | ------------------------------------------------ |
| **IA Stratégique**        | +1 slot de flotte simultanée par niveau          |
| **Scanner cosmique**      | Améliore la profondeur des rapports d'espionnage |
| **Réacteur à Impulsions** | Débloque et améliore les vaisseaux intermédiaires |
| **Systèmes Balistiques**  | +10% Attaque de tous les vaisseaux par niveau    |
| **Champs Déflecteurs**    | +10% Bouclier de tous les vaisseaux par niveau   |
| **Alliages Nano-Tressés** | +10% Structure de tous les vaisseaux par niveau  |

### ⚡ Technologies Avancées

| Technologie                 | Effet                                                                    |
| --------------------------- | ------------------------------------------------------------------------ |
| **Propulsion Quantique**    | +30% vitesse de toutes les flottes par niveau                            |
| **Noeuds d'hyperdensité**   | +5% capacité de fret de tous les vaisseaux par niveau                    |
| **Maillage Neuronal**       | Fusionne la puissance de laboratoire entre plusieurs planètes            |
| **Cartographie Solarienne** | +1 slot de colonisation · expéditions simultanées = `min(5 ; ⌊√niveau⌋)` |

### 💀 Technologies Spéciales

| Technologie                       | Prérequis                    | Effet                            |
| --------------------------------- | ---------------------------- | -------------------------------- |
| **Manipulation Gravitationnelle** | 300 000 unités d'énergie     | Débloque le **Titan Astral** (RIP) |
| **Surchauffe Plasmatique**        | Systèmes Balistiques Niv. 12 | +30% bonus d'Attaque massif      |

> ⚠️ **Attention**
>
> **Défi Gravitationnel** — La **Manipulation Gravitationnelle** nécessite de générer **300 000 unités d'énergie en une seule requête**. Cet exploit est un défi de méta-jeu collectif qui peut nécessiter la coordination d'une alliance entière.
