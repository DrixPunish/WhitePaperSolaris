# 5.6 Défenses Planétaires

Les défenses sont des structures **fixes** construites sur une planète ou une lune. Elles ne consomment pas de carburant et ne peuvent pas se déplacer.

| Défense                            | Classe        | Usage                                                      |
| ---------------------------------- | ------------- | ---------------------------------------------------------- |
| **Tourelle Cinétique**             | Légère        | Salves de projectiles métalliques — défense de masse       |
| **Canon à Impulsion**              | Légère        | Rafales d'énergie, tir rapide contre les petites unités    |
| **Canon de Faisceau**              | Intermédiaire | Faisceau continu capable de percer les blindages moyens    |
| **Projecteur Ionique**             | Lourde        | Décharge ionisée qui affaiblit les boucliers ennemis       |
| **Canon de Masse**                 | Lourde        | Obus hyper-denses — dévastateur contre les vaisseaux lourds |
| **Canon Solaris**                  | Élite         | Plasma surchauffé — la défense la plus puissante           |
| **Petit / Grand Bouclier Planétaire** | Bouclier   | Dôme énergétique — absorbe massivement les dégâts          |

> ✅ **Bon à savoir**
>
> **Reconstruction post-combat** — Dans Solaris, les défenses ont une probabilité de **70% de reconstruction automatique** après un combat. Ce taux est amélioré via l'officier **Ingénieur**, créant une résilience économique absente d'OGame.
