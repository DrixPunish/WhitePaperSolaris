# 5.6 Défenses Planétaires

Les défenses sont des structures **fixes** construites sur une planète ou une lune. Elles ne consomment pas de carburant et ne peuvent pas se déplacer.

| Défense                 | Classe        | Usage                                               |
| ----------------------- | ------------- | --------------------------------------------------- |
| Lanceur de Missiles     | Légère        | Défense de masse, excellent rapport coût/efficacité |
| Canon Laser Léger       | Légère        | Anti-chasseurs en nombre                            |
| Canon Laser Lourd       | Intermédiaire | Anti-vaisseaux moyens                               |
| Canon à Ions            | Lourde        | Anti-flotte, bon RF contre croiseurs                |
| Canon de Gauss          | Lourde        | Très haute Attaque, idéal contre vaisseaux T4–T5    |
| Canon à Plasma          | Élite         | Défense la plus puissante — anti-tout               |
| Dôme Petit / Grand      | Bouclier      | Absorbe massivement les dégâts avant destruction    |
| Lanceur Interplanétaire | Stratégique   | Attaque des planètes dans le même système           |
| ABM                     | Stratégique   | Intercepte les missiles interplanétaires entrants   |

> ✅ **Bon à savoir**
>
> **Reconstruction post-combat** — Dans Solaris, les défenses ont une probabilité de **70% de reconstruction automatique** après un combat. Ce taux est améliorable via l'officier **Ingénieur (NFT)**, créant une résilience économique absente d'OGame.
