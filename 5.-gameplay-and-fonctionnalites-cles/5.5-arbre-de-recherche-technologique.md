# 5.5 Arbre de Recherche Technologique

Le **Laboratoire de Recherche** est le moteur de progression long-terme. Chaque technologie débloque ou améliore des capacités clés. La recherche est planétaire mais son bénéfice est global (empire entier).&#x20;

### **🔩 Technologies de Base**

| Technologie                 | Effet                                            |
| --------------------------- | ------------------------------------------------ |
| Technologie des Ordinateurs | +1 slot de flotte simultanée par niveau          |
| Espionnage                  | Améliore la profondeur des rapports d'espionnage |
| Propulsion à Impulsion      | Débloque et améliore les vaisseaux de tier 1–2   |
| Armement                    | +10% Attaque de tous les vaisseaux par niveau    |
| Bouclier                    | +10% Bouclier de tous les vaisseaux par niveau   |
| Protection des Vaisseaux    | +10% Structure de tous les vaisseaux par niveau  |

***

### **⚡ Technologies Avancées**

| Technologie                         | Effet                                                          |
| ----------------------------------- | -------------------------------------------------------------- |
| Propulsion Hyperespace              | +30% vitesse de toutes les flottes par niveau                  |
| Technologie Hyperespace             | +5% cargaison de tous les vaisseaux civils par niveau          |
| Réseau de Recherche Intergalactique | Fusion de la puissance de laboratoire entre plusieurs planètes |
| Astrophysique                       | +1 slot de colonisation · +1 expédition simultanée par niveau  |

***

### **💀 Technologies Spéciales**

| Technologie        | Prérequis                | Effet                               |
| ------------------ | ------------------------ | ----------------------------------- |
| Graviton           | 300 000 unités d'énergie | Débloque le Titan (RIP)             |
| Technologie Plasma | Armement Niv. 12         | +30% bonus d'Attaque massif         |
| Terraformation     | Nanotech Niv. 10         | Débloque le Terraformeur planétaire |

> ⚠️ **Attention**
>
> **Challenge Graviton** — La Technologie Graviton nécessite de générer **300 000 unités d'énergie en une seule requête**. Cet exploit est un défi de méta-jeu collectif qui peut nécessiter la coordination d'une alliance entière.
