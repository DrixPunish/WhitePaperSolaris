# 5.13 Anti-Bashing System

To prevent a player from relentlessly harassing another and putting them off the game, a system was designed to limit the number of daily attacks an aggressor can make on their target.\
\
For each _attacker - target_ pair there is an aggressiveness score, visible to the attacker in the fleet dispatch menu. This score cannot exceed 6. If sending an attack would push the score above 6, the attacker can no longer attack that target.\
\
The formula to determine an attack's aggressiveness score is:

$$VA = P.A / P.C$$\
\
Where:\
VA = Aggressiveness value of the attack\
P.A = Points of the attacking player\
P.C = Points of the target player\
\
When an attack occurs, the aggressiveness score of that _attacker - target_ pair increases by the attack's VA.\
\
When an attack happened more than 24h ago, its VA is removed from the aggressiveness score.

> So, when an attacker has not attacked a target for at least 24h, the aggressiveness score of the _attacker - target_ pair is 0.\
> \
> Two players with the same number of points can attack each other 6 times within a rolling 24h window.\
> \
> If the point difference between two players is large:\
> \- The stronger one can attack the weaker one very little.\
> \- The weaker one can attack the stronger one a lot.

{% hint style="warning" %}
In all cases, the attack is impossible:\
\- If the target has fewer than 100 points.\
\- If the attacker exceeds the point multiple allowed by the target's tier (see [5.12 Shields & Protections](5.13-boucliers-and-protections.md)).
{% endhint %}
