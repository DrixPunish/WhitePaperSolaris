# 4.5 Phase 5 — Sovereignty

> **Objectif :** Décentraliser progressivement la gouvernance du projet. Les détenteurs de SLR prennent en main les décisions clés de l'univers Solaris.

#### 5.1 DAO Solaris

* Déploiement du contrat de gouvernance DAO (votes on-chain avec SLR)
* Système de propositions : toute adresse avec un seuil de SLR peut soumettre une proposition
* Votes sur : paramètres d'univers, nouvelles mécaniques, allocations de trésorerie
* Trésorerie DAO publique et auditée

#### 5.2 Gouvernance des Univers

* Les joueurs votent sur les paramètres des futurs univers (vitesse, économie, durée)
* Création d'univers thématiques décidés par la communauté
* Blacklist / whitelist d'adresses par vote communautaire (anti-cheat)

#### 5.3 Écosystème & SDK

* SDK public pour permettre à des développeurs tiers de créer des outils pour Solaris
* API publique de données on-chain (stats, classements, marchés)
* Programme de grants pour les contributeurs de l'écosystème
* Intégration avec des guildes de gaming Web3 (Yield Guild Games, etc.)

#### 5.4 Expansion Mobile

* Application native iOS et Android
* Notifications push natives (attaques, construction, espionnage)
* Wallet intégré mobile

#### 5.5 Pérennité & Décentralisation

* Migration progressive vers une infrastructure décentralisée (IPFS pour les assets)
* Réduction de la dépendance aux serveurs centralisés
* Plan de continuité : le jeu continue même si l'équipe fondatrice se retire
